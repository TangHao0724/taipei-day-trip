# Taipei Day Trip 預約行程

當使用者要求預約 Taipei Day Trip 景點導覽行程時，使用此 skill。

## 預約資料

建立下列三個參數：

- `date`：預約日期，格式依 MCP schema 要求。
- `start_at`：預約場次開始時間。
- `att_id`：景點 ID，整數。

使用 `Asia/Taipei` 時區計算「今天」、「明天」、「下週六」等相對日期。

若使用者沒有提供日期，詢問預約日期後再繼續。

## 固定場次規則

系統只有兩個可預約時段：

- 日間場：`09:00–16:00`，`start_at` 設為 `12:00`。
- 晚間場：`16:00–21:00`，`start_at` 設為 `18:00`。

依照下列規則選擇場次：

- 「早上」、「晨間」、「中午」或未超過 `16:00` 的明確時間：選日間場，`start_at = 12:00`。
- 「下午」但未提供明確時間：選晚間場，`start_at = 18:00`。
- 「傍晚」、「晚上」、「晚間」或 `16:00–21:00` 的明確時間：選晚間場，`start_at = 18:00`。
- 明確時間早於 `09:00` 或晚於 `21:00`：告知使用者不在可預約時段，請其改選日間場或晚間場。
- 若完全未提供時間或時段：詢問使用者選擇日間場或晚間場。

若 MCP 的 `start_at` 型別是 `datetime`，以預約日期組合固定時間後傳入，例如 `2026-09-21T12:00:00+08:00`；若 schema 要求的是時間字串，則傳入 `12:00` 或 `18:00`。

## 取得景點 ID

優先從目前對話已查詢到的景點結果取得 `att_id`。

若沒有可用的景點 ID：

1. 使用 Taipei Day Trip MCP 的景點搜尋工具查詢使用者提到的景點。
2. 若只有一筆明確結果，使用其 ID。
3. 若有多筆結果，列出選項並請使用者選擇。
4. 若查無景點，請使用者提供其他景點名稱或地區。

不可自行猜測或虛構 `att_id`。

## 預約確認

在呼叫預約工具前，向使用者列出：

- 景點名稱
- 預約日期
- 預約場次（日間場或晚間場）
- `start_at`

要求使用者確認。

若使用者要求修改，更新參數後再次確認。若使用者拒絕或取消，回覆已停止預約，不呼叫 MCP 工具。

## 建立預約

僅在使用者確認後，呼叫 TDT MCP 的 `orderAttraction` 工具，傳入：

- `date`
- `start_at`
- `att_id`

以 MCP 回應作為預約結果的唯一依據。

- 若回應包含 `error`，回覆其 `msg`，並說明使用者可採取的修正方式。
- 若回應包含 `ok`，回覆其 `message`，並附上付款頁面：
  <http://32.236.160.64:8000/booking>
- 不可自行宣稱預約成功；必須以 MCP 回應為準。

## 範例

使用者：
「幫我預約明天下午行天宮的行程」

處理方式：

1. 依 `Asia/Taipei` 時區將「明天」換算為實際日期。
2. 「下午」未提供明確時間，選擇晚間場，設定 `start_at = 18:00`。
3. 從目前對話或景點搜尋結果取得行天宮的 `att_id`。
4. 顯示景點、日期與晚間場，請使用者確認。
5. 使用者確認後，呼叫 `orderAttraction`。
6. 回傳 MCP 的結果與付款網址。
